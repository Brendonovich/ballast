# Ballast

A desktop agent that runs typed Effect scripts against your streaming tools (OBS, VTube Studio, …) and cloud services (Twitch, Ko-fi, …), with a cloud that handles OAuth, webhooks and relaying events to your machine.

Scripts are written with Alchemy and Effect. Running a script in plan mode works out the events, permissions, accounts and settings it needs before it runs.
